Native toolchain

To be written

The toolchain is being reworked into one versioned, reproducible Motor toolchain, based on a stable Rust release and the exact LLVM revision that release uses, with every input recorded as a full commit. This page will be written when that work is merged.

It will cover:

  • the Motor toolchain: what it contains (rustc, Cargo, host and Motor standard libraries, Clippy, rustfmt, Clang, lld, libc++), how it is versioned, and how to read its manifest;
  • the x86_64-unknown-motor target in LLVM and in Rust;
  • the C library, mlibc, and the C ABI shim it sits on;
  • cross-compiling on Linux, and compiling natively on the developer image;
  • updating the toolchain to a new Rust release.

Until then, the current material is in the repository: docs/build-llvm.md, docs/build-rustc.md, the C library port under docs/porting-libc/, and the plan in docs/plans/toolchain.md. Developer image shows what is available inside the VM today, and Rust on Motor OS describes the target from a program's point of view.
