Usage: ssh [options] [user@]host [command [argument ...]]

Connect to a remote host. Without a command, open an interactive shell
(requires a terminal). With a command, run it and return its exit status.
Use brackets around IPv6 addresses, for example motor@[::1].

Options:
  -h, --help           Show this help and exit successfully
  -p port             Remote port (default: 22)
  -i file             Private key file (may be repeated)
  -t                  Require an interactive terminal
  -T                  Disable terminal allocation
  -L [bind:]port:host:hostport
                      Forward a local TCP port through the remote host
  -D [bind:]port      Listen as a SOCKS4/4a/5 CONNECT proxy (no authentication)
  -R [bind:]port:host:hostport
                      Forward a remote TCP port to a target on this client
  -N                  Run no command or shell (tunnel only)
  -g                  Default local forwards to all interfaces
  -o Key=Value        Set a connection option (listed below)
  -F file             Select a config file (none or /dev/null: disable config)
  -J [user@]host[:port][,...]
                      Connect through one or more jump hosts
  --                  End options

Connection options for -o:
  HostName=host                         Override the connection address
  User=user                             Set the remote login name
  Port=port                             Set the remote port
  IdentityFile=path                     Add a private key (none: no default key)
  ProxyJump=[user@]host[:port][,...]      Jump hosts (none: connect directly)
  IdentitiesOnly=yes|no                  Use configured identity files only
  StrictHostKeyChecking=ask|yes|accept-new
                                        Host key policy (default: ask)
  UserKnownHostsFile=path                Override the known-hosts file
  BatchMode=yes|no                       Disable prompts (default: no)
  ConnectTimeout=seconds                Connection setup timeout (0: disabled)
  ServerAliveInterval=seconds           Keepalive interval (0: disabled)
  ServerAliveCountMax=count             Unanswered keepalives (default: 3)
  LocalForward="[bind:]port host:port"   Add a local TCP forward
  DynamicForward=[bind:]port            Add a SOCKS listener
  RemoteForward="[bind:]port host:port"  Add a remote TCP forward (port 0: allocate)
  GatewayPorts=yes|no                   Default to all interfaces (default: no)
  ExitOnForwardFailure=yes|no           Exit on setup failure (default: no)

Configuration (Motor OS):
  Config file:         /user/cfg/ssh/config (OpenSSH syntax)
  Default private key: /user/cfg/ssh/id_ed25519
  Known hosts:         /user/cfg/ssh/known_hosts
  The default user is $USER, or motor if USER is unset or empty.
  Host blocks support aliases, multiple patterns, *, ? and ! negation.
  Supported settings are listed above. Command-line settings take priority;
  otherwise the first matching scalar wins. IdentityFile, LocalForward,
  DynamicForward and RemoteForward entries accumulate. Forwards run only on
  the final destination. Allocated remote ports are printed to stderr.
  Include, Match, ProxyCommand, agents and value expansion are unsupported.
  Paths are literal; use /user/cfg/ssh/key rather than ~/.ssh/key.

Examples:
  ssh motor@host
  ssh -p 2222 motor@host /system/bin/echo hello
  ssh -i /user/cfg/ssh/id_ed25519 -o BatchMode=yes motor@host command
  ssh -J motor@gateway motor@private-host
  ssh -N -L 8080:localhost:80 motor@host
  ssh -N -D 1080 motor@host
  ssh -N -R 0:localhost:80 motor@host

Key installation:
  ssh-copy-id -i key.pub user@host
                       Install a key for a server that reads .ssh/authorized_keys
  ssh-copy-id -t PATH -i key.pub user@host
                       Install a key into the file PATH. Required for Motor OS
                       servers, where PATH is /user/cfg/ssh/authorized_keys.NAME
                       for login name NAME

Related commands: scp, sftp, ssh-keygen, ssh-copy-id.
